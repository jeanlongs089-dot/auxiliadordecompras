# Auxiliador de Compras

Plataforma B2B2C que conecta a experiência do consumidor dentro do supermercado à inteligência de intenção para o varejista.

> Seu cliente encontra. Sua loja entende.

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS
- Supabase (PostgreSQL e Auth)
- Express/Vercel Functions

## Desenvolvimento local

1. Copie `.env.example` para `.env` e configure o Supabase.
2. Instale as dependências com `npm install`.
3. Inicie frontend e API com `npm run dev`.

```bash
npm run build
npm run check
npm run lint
npm run db:test
```

Detalhes adicionais estão em [SETUP.md](./SETUP.md).
